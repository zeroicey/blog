这篇文章按理说该叫《白嫖指南》，但为了观感，我决定给它取个正经点的名字——「资源的合理利用」。毕竟这 300 块钱就明晃晃摆在阿里云那儿，一年白送一次，你不去领，反而是对资源的浪费。

事情的起因很简单：阿里云有个每年一次的学生认证活动。认证通过就有 300 元无门槛代金券，**这 300 元可以直接用于 AI 额度**——也就是在「阿里百炼」上调用模型，像 `DeepSeek PRO v4 0813`、`DeepSeek Flash v4 0731` 这种高级模型，都能用它白嫖。

整套流程没有任何门槛，三步走完。下面按顺序来。

# 领取 300 元代金券

打开 [阿里云学生认证页面](https://university.aliyun.com/)：

![阿里云学生认证页面](https://s3.blog.zeroicey.me/20260827220000.png)

步骤就是「登录 → 认证 → 领券」：

1. **登录阿里云**：用支付宝登录，或者其他你习惯的方式都行。
2. **学生认证**：通过支付宝完成学生身份认证。这一步每年一次，认证过就能领。
3. **领取代金券**：认证通过后，直接领那张 300 元无门槛代金券。

几个值得注意的细节（都是从活动规则里抠出来的）：

- **无门槛、一年有效**：从领取那天算起，有效期 1 年，过期作废。
- **可拆着用**：只要单笔订单不超过券内余额，就能无限次用，直到余额清零。
- **面向高校学生**：专科、本科、硕士、博士、在职研究生等都算，学籍在就行。

券到手之后，重点来了——怎么把它变成 AI 额度。

# 去百炼创建 API Key

打开 [百炼控制台](https://bailian.console.aliyun.com/cn-beijing?tab=model#/api-key)，进到 API-KEY 这个 tab。页面上方就能看到两个关键信息：**Base URL** 和 **创建 API Key** 的按钮。

![百炼控制台：Base URL 与创建 API Key 按钮](https://s3.blog.zeroicey.me/20260827220001.png)

点一下那个「创建我的 API-KEY」按钮：

![创建 API Key 弹窗](https://s3.blog.zeroicey.me/20260827220002.png)

填个 Key 的名字（随便起，能认出来就行），确认之后，你就拿到了一串 API Key：

![显示 API Key](https://s3.blog.zeroicey.me/20260827220003.png)

这里有一个**极其容易踩坑的点**：Base URL 每个人都是独立的，所以一定要**复制你自己页面上的那个**，别照抄别人文章里的。API Key 也是——创建后立刻复制保存，这玩意关了弹窗之后通常就看不全了。

# 结尾

整个流程其实就是这么简单：

1. 阿里云支付宝登录 → 学生认证 → 领 300 元代金券；
2. 去百炼创建 API Key，复制自己的 Base URL。

之后如果要使用，你只需要记住两样东西就够了：**Base URL** 和 **API Key**。剩下的就是找个小模型 Agent（或者自己写几行调用代码），把这两样填进去，`deepseek-pro-v4-0813`、`deepseek-flash-v4-0731` 随便用。

白嫖这种事，谈不上什么技巧，核心就一条：**官方白送的资源，领就完了。**
